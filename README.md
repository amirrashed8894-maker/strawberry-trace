# تتبع كراتين الفراولة — شركة الراشد للتجارة

نظام تتبع للوتات التصدير (فراولة مجمدة). رقم واحد لكل عربية / لوت، وكل استيكرات اللوت تحمل نفس الرقم مكرراً على الاستيكر (بدون QR)، مع عنوان الموقع أسفل الملصق.

## النموذج

- العربية ≈ لوت واحد، ورقم لوت واحد (مثل `FS-2611-01`).
- عدد الكراتين = سقف (وزن الميزان ÷ وزن الكرتونة).
- عدد الاستيكرات = عدد الكراتين + احتياطي قابل للضبط (افتراضي 10٪).
- الطباعة: PDF فيه N استيكر متطابق (نفس الرقم مكرر داخل كل ملصق).
- «اطبع الفرق»: نسخ إضافية من **نفس** رقم اللوت، مش أرقام جديدة.
- ميزان العربية قابل للتعديل في أي وقت، والعدد يتحدث لحظياً. لو قلّ الوزن عن الكراتين المتحمّلة يظهر تحذير.
- تحميل الحاويات بعدد الكراتين، مع منع التحميل فوق عدد كراتين اللوت. الحاوية ممكن تجمع أكثر من لوت، واللوت ممكن يتوزع على أكثر من حاوية.
- الصفحة العامة: بيانات اللوت + كل حاوياته، أو «لم يتم التحميل بعد». القراءة بالكاميرا (OCR) تختار الرقم الظاهر أكثر والموجود في النظام. الرابط `/?c=FS-2611-01` شغال.
- التواريخ ميلادي يوم/شهر/سنة (نص، توقيت القاهرة)، مش حقل التاريخ الافتراضي للمتصفح.
- لوحة الإدارة مفتوحة بدون تسجيل دخول (`/?p=admin`). الكتابة تتم عبر دوال `SECURITY DEFINER` فقط، والجداول مقفولة عن `anon`.
- دفعات أرقام الكراتين القديمة (رقم لكل كرتونة) محفوظة للعرض وإعادة الطباعة فقط، والنظام الجديد لا يستخدمها في اللوتات الجديدة.

## الإدارة

- اللوتات: إنشاء، الميزان، الاحتياطي، الطباعة والفرق.
- الحاويات: إنشاء وتحميل بعدد الكراتين.
- بحث وتتبع، الإعدادات (نسبة الاحتياطي والحقول الظاهرة للعميل).
- الدفعات السابقة من شاشة الإعدادات.
