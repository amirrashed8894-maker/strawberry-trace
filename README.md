# تتبع الكرتون — شركة الراشد للتجارة

نظام تتبع لكراتين الفراولة المجمدة: طباعة أرقام ثابتة مقدماً، ثم تخصيص اللوت والحاوية لاحقاً.

الرابط: https://strawberry-trace.onrender.com

## طريقة العمل
1. توليد دفعة أرقام وطباعة الاستيكرات (الرقم كبير، ويتكرر في شبكة تغطي الاستيكر، مع عنوان موقع التتبع أسفل الملصق).
2. تلزيق استيكر على كل كرتونة.
3. تخصيص مدى أرقام للوت (عربية المورد) ثم للحاوية.
4. العميل يدخل الرقم على الموقع، أو يصوّر الكرتونة فتُقرأ الكتابة تلقائياً، فتفتح صفحة التفاصيل.

## التقنية
واجهة PWA ثابتة على Render، وقاعدة البيانات والمصادقة على Supabase مع RLS.
