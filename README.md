# تتبع الكرتون — شركة الراشد للتجارة

نظام تتبع لكراتين الفراولة المجمدة: طباعة أرقام ثابتة (QR) مقدماً، ثم تخصيص اللوت والحاوية لاحقاً.

الرابط: https://strawberry-trace.onrender.com

## طريقة العمل
1. توليد دفعة أرقام وطباعة الاستيكرات (الرقم مكرر على الاستيكر).
2. تلزيق استيكر على كل كرتونة.
3. تخصيص مدى أرقام للوت (عربية المورد) ثم للحاوية.
4. العميل يصوّر الـ QR بكاميرا الموبايل، فتفتح صفحة التفاصيل.

## التقنية
واجهة PWA ثابتة على Render، وقاعدة البيانات والمصادقة على Supabase مع RLS.
